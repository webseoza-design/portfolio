AKBER ALI KHAN — DIGITAL MARKETING PORTFOLIO
================================================

FILES
- index.html : Main portfolio website
- style.css  : All styling and responsive layouts

HOW TO VIEW
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in your browser.

BEFORE PUBLISHING
1. In index.html, find:
   action="mailto:YOUR_EMAIL@example.com"
   Replace YOUR_EMAIL@example.com with your real email address.
2. The contact form uses mailto. It opens the visitor's configured email app; it does not send submissions to a server.
3. Add your real profile photo and verified portfolio/case studies if you have them.
4. The website uses Google Fonts from an external service. If offline, it will fall back to system fonts.
5. Update metadata, canonical URL, sitemap, and robots.txt after choosing your final domain.

TECHNOLOGY
- HTML5
- CSS3
- No JavaScript
- No framework or build step
